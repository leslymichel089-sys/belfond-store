## Structure

- `index.html` — page d'accueil (présentation, vitrine produits, propriétaire, contact)
- `politique-confidentialite.html` — politique de confidentialité
- `propriete-intellectuelle.html` — déclaration de propriété intellectuelle numérique
- `style.css` — feuille de style (ivoire, charbon, doré)
- `assets/proprietaire.jpg` — portrait officiel de la propriétaire
- `assets/produits/produits-1.jpg` … `produits-8.jpg` — photographies des produits
  (à déposer dans ce dossier : elles s'afficheront automatiquement dans la vitrine)
